Entry for the make.fun bounty **"Famous Last Words: The Funniest Epitaph"** (slug `u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406`).

`main.ts` writes a single one-line tombstone epitaph to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The entry:

> I died doing what I loved: ignoring the check engine light.

It sets up a heroic dying boast — "doing what I loved" — then undercuts it with a painfully ordinary habit, the warning light everybody ignores until it is too late. One short line, carved-in-stone voice, no explanation needed.
